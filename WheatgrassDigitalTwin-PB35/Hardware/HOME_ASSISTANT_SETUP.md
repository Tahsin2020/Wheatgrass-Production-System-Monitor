# Home Assistant Setup

This document provides links to setup guides for Home Assistant and ESPHome integration.

## Home Assistant Installation

To install Home Assistant, follow the official installation guide:

**[Home Assistant Installation Guide](https://www.home-assistant.io/installation/)**

This guide covers various installation methods including:
- **Home Assistant Operating System** - Recommended for Raspberry Pi or dedicated hardware
- **Virtual Machine** - Run on VMware, VirtualBox, or other hypervisors

## ESPHome Integration

Once Home Assistant is installed, set up ESPHome to integrate your ESP devices:

**[ESPHome Getting Started with Home Assistant](https://esphome.io/guides/getting_started_hassio/)**

This guide will walk you through:
- Installing the ESPHome add-on in Home Assistant
- Creating your first ESPHome configuration
- Connecting ESP devices to Home Assistant
- Managing and updating ESP firmware

## Project Configuration
